最大规模具身大模型挑战赛落幕，48 小时真机总决赛比出了什么？

极客公园

The first Ant Lingbo Embodied Large Model Challenge concluded in Shanghai, with 15 teams using the same open-source LingBot-VLA 2.0 model, robot, and compute to complete real-world manipulation tasks within 48 hours. The winning team, TARS, scored 82 by combining large-model-based object recognition with targeted data collection and training acceleration, while third-place SST achieved 65.87 with only 13 additional data samples by integrating DeepSeek for task understanding and a vision segmentation model for object localization.

首届蚂蚁灵波具身大模型挑战赛在上海收官，15支队伍用同一款开源模型LingBot-VLA 2.0、同一款机器人和统一算力，在48小时内完成真机操作任务。冠军TARS队靠大模型识别目标加针对性补数据拿到82分，季军SST队只补了13条数据，通过接入DeepSeek做任务理解、视觉分割模型定位物体，就拿到65.87分。比赛说明：基础模型越强，开发者越比拼谁更懂模型能力、谁能用最少的数据和工具把能力释放出来。

  • All 15 finalist teams used the same LingBot-VLA 2.0 model, COBOT MAGIC robot, and on-site compute, completing tasks like fruit placement, cosmetics storage, and dual-arm sweeping.
  • Winning team TARS scored 82 by using large models to identify targets and distractors, masking irrelevant regions, and optimizing data for the hardest sweeping task.
  • Third-place SST used only 13 additional data samples, combining DeepSeek for task understanding and a vision segmentation model for object localization, while freezing some pretrained parameters to preserve general capabilities.
💡 Why it matters: The challenge demonstrates that strong foundation models lower the barrier to embodied AI development, shifting the focus from building models from scratch to data engineering, tool integration, and preserving general capabilities during fine-tuning.
🇨🇳 对开发者来说，具身智能的竞争正从“造模型”转向“用好模型”——数据工程、工具链整合和避免微调破坏通用能力，才是拉开差距的关键。
