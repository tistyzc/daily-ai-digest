Reference same-repository actions with self-repository syntax

GitHub Blog Changelog

GitHub Actions introduces a new self-repository syntax ($/) to reference actions or reusable workflows within the same repository, resolving to the exact commit being run without requiring a checkout. This replaces the previous need for ./ syntax with checkout or hardcoded versions, ensuring consistency with commit SHA pinning and supporting enterprise policies. The feature is available on github.com and requires runner version 2.336.0 or newer.

GitHub Actions 推出了新的自仓库语法（$/），让你可以直接引用同一仓库内的 action 或可复用工作流，无需 checkout，且自动匹配当前运行的 commit。以前要么用 ./ 加 checkout，要么硬编码版本，现在终于可以彻底告别这种麻烦，还能轻松满足企业要求的长 SHA 固定策略。该功能已在 github.com 上线，需要 runner 2.336.0 或更高版本。

  • New $/ syntax references same-repository actions or reusable workflows at the exact running commit, no checkout needed.
  • Works everywhere ./ syntax works, including steps, composite actions, nested composition, and reusable workflow calls.
  • Automatically matches the current ref, maintaining consistency with commit SHA pinning and enabling enterprise pinning policies.
💡 Why it matters: This simplifies internal action composition, reduces maintenance overhead, and helps teams enforce strict commit SHA pinning policies without breaking internal references.
🇨🇳 简化了仓库内 action 的组装方式，减少维护成本，同时让团队能轻松执行严格的 commit SHA 固定策略，内部引用也不会乱。
