Security & Safety (1)

当智能体开始替人花钱，如何证明「它是谁」？

极客公园 🔴 Factual

Ant Group unveiled APASS at the 2026 Bund Summit, a trust infrastructure for agentic commerce built on the KYA (Know Your Agent) concept. It verifies an agent's identity through code fingerprints, runtime environment checks, and linkage to KYC/KYB legal accountability, while constraining what an agent may buy via scoped authorization and intent-drift detection. The system aims to resolve who bears responsibility when autonomous agents spend money and things go wrong.

蚂蚁集团在外滩大会发布 APASS，一套面向智能体商业的信任基础设施，核心是 KYA（认知你的智能体）。它从代码指纹、运行环境、法定责任人三个维度核验 Agent 身份，并用授权范围（Scope）和意图漂移检测管住「它到底能花什么钱」。说白了，就是让 Agent 替你下单时，商家认得出它是谁、你也兜得住底。

  • APASS verifies agent identity via software fingerprints, hardware-backed runtime environment checks, and binding to KYC/KYB legal entities.
  • Scoped authorization (L2/L3) lets agents execute micro-transactions without interrupting users, bounded by budget, category, merchant whitelist, and time window.
  • Intent security models cross-check each transaction against the original prompt to block drift, such as buying soda turning into buying gold.
💡 Why it matters: For developers building agentic workflows, APASS signals that payment trust, identity verification, and scoped permissions are becoming first-class infrastructure concerns rather than afterthoughts.
🇨🇳 对做 Agent 的开发者来说，支付信任、身份核验和权限边界正在从「以后再说」变成必须一开始就设计进去的基础设施。

In the 410th issue of his weekly tech digest, Ruan Yifeng explains the three core mechanisms behind how large language models answer questions: the parameter mechanism (knowledge compressed into billions of weights), the reasoning mechanism (deriving knowledge not stored in parameters), and the web-search mechanism (retrieving information the model cannot know or infer). The issue also covers public speaking tips, tech news like a flat-pack chair and virtual avatar concerts, and articles on Git worktree and AI industry shifts.

阮一峰周刊第410期用通俗易懂的方式讲清了AI回答问题的三大机制：参数机制（把人类知识压缩进几千亿个权重里）、推理机制（靠逻辑推出参数里没有的知识）、联网机制（前两者都搞不定时上网搜）。此外还有公开演讲的六个窍门、华硕自行车助力器、虚拟化身演唱会等科技动态，以及Git worktree使用详解等好文推荐。

  • LLMs answer questions through three mechanisms: parameters (compressed knowledge), reasoning (derived knowledge), and web search (retrieved knowledge)
  • Parameter mechanism: models like GLM 5.3 have 744 billion parameters encoding relationships between tokens, trained to represent human knowledge
  • Reasoning mechanism: models infer knowledge not stored in parameters using logical rules, e.g., calculating population growth from birth and death rates
💡 Why it matters: This article gives developers and AI practitioners a clear, non-technical mental model of how LLMs work, helping them better understand model capabilities and limitations when building AI applications.

The issue also covers Bluetooth-reading traffic cameras, sonic fire extinguishers, windowless jets, and the longest line of sight on Earth.

阮一峰周刊第408期把大模型的「缓存命中价」讲透了：命中缓存时输入 Token 只要未命中价格的五十分之一，因为前缀计算结果被复用，几乎不耗算力。文中还对比了各家缓存有效期（Anthropic 5分钟、DeepSeek/OpenAI 10~30分钟、Google 1小时），并建议 Agent 把保活请求从每30秒改成每4分钟。此外还有蓝牙识别摄像头、声波灭火、无舷窗飞机等有趣科技动态。

  • Cached input tokens can be up to 50x cheaper than uncached ones because the model reuses prior prefix computations instead of recalculating attention.
  • Cache TTL varies by provider: Anthropic 5 minutes, DeepSeek 10 minutes, OpenAI 10-30 minutes, Google up to 1 hour.
  • AI agents keep caches alive by sending periodic requests; the latest advice is to ping every 4 minutes rather than every 30 seconds to cut costs.
💡 Why it matters: Developers building LLM agents can significantly cut token costs by structuring prompts to maximize cache hits and tuning keep-alive intervals to match provider TTLs.
🇨🇳 做 AI Agent 的开发者可以通过优化提示词结构、提高缓存命中率，并合理设置保活间隔，大幅降低 Token 成本。
