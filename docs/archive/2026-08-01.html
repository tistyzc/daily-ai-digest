Stateless MCP has recaptured my interest (and inspired mcp-explorer and datasette-mcp)

Simon Willison's Blog 🔴 Factual

Stateless MCP, part of the MCP 2.0 specification (2026-07-28), simplifies the protocol by eliminating the need for session initialization and state management, reducing tool calls to a single HTTP request. This change has reignited Simon Willison's interest in MCP, leading him to build three implementations including mcp-explorer and datasette-mcp. The stateless approach makes MCP easier to implement, audit, and control, making it more accessible for smaller models and scalable web applications.

无状态MCP（MCP 2.0规范的一部分）通过移除会话初始化和状态管理，将工具调用简化为单个HTTP请求，大幅降低了客户端和服务端的实现复杂度。这一变化让Simon Willison重新燃起对MCP的兴趣，并促使他构建了mcp-explorer和datasette-mcp等三个实现。无状态设计让MCP更易于审计和控制，也更适合小型模型和可扩展的Web应用。

  • Stateless MCP eliminates the two-step session initialization (initialize + tools/call) required by legacy MCP, reducing tool calls to a single HTTP request.
  • The new spec uses headers like MCP-Protocol-Version and Mcp-Method, removing the need for server-side session state and routing concerns.
  • Simon Willison built three stateless MCP implementations in one week, including mcp-explorer and datasette-mcp, demonstrating the reduced complexity.
💡 Why it matters: This simplifies MCP adoption for developers, enabling faster implementation of tool servers and clients, and making MCP viable for lightweight models and scalable web services.
🇨🇳 这降低了MCP的采用门槛，开发者可以更快地实现工具服务器和客户端，并使MCP适用于轻量级模型和可扩展的Web服务。

Stacked pull requests are now in public preview

  • Stacked PRs are an ordered series of small, focused pull requests that can be reviewed independently and merged together in one click.
  • The feature is built into GitHub, working with existing reviews, checks, and branch protections, and supports CLI, web, mobile, and Copilot.
  • Early adopters like Vercel and TED report faster, more accurate reviews and reduced friction in shipping large features.
💡 Why it matters: This reduces the review bottleneck for large changes, enabling parallel review and faster, safer merges, which is especially valuable in AI-assisted development where PRs tend to grow large.
🇨🇳 这缓解了大型变更的审查瓶颈，支持并行审查和更快速、更安全的合并，尤其在 AI 辅助开发导致 PR 体积增大的场景下价值显著。
