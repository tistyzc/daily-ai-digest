科技爱好者周刊（第 410 期）：你需要知道的 AI 三种机制

阮一峰周刊 🔴 Factual 🟢 Privacy

In the 410th issue of Ruan Yifeng's weekly newsletter, the author explains three core mechanisms behind how large language models answer questions: the parameter mechanism (knowledge compressed into billions of weights via training), the reasoning mechanism (deriving knowledge not stored in parameters through logical inference), and the web-access mechanism (using agents to search the internet for information that cannot be parameterized or inferred). The issue also covers public speaking tips, tech news like a flat-pack chair and virtual avatar concerts, and articles on AI risks, the anonymous Ox Alpha model (revealed to be GLM 5.3 Flash), Git worktree, and web fingerprinting.

阮一峰周刊第410期用通俗易懂的方式拆解了AI回答问题的三大机制：参数机制（把人类知识压缩进几千亿个权重里）、推理机制（靠逻辑推导出参数里没存的知识）、联网机制（让Agent上网搜前两者都搞不定的信息）。周刊还聊了公开演讲的窍门、平板椅子、虚拟化身演唱会等科技趣闻，以及盖茨对AI态度的转变、匿名模型Ox Alpha被证实是智谱GLM 5.3 Flash等文章。

  • LLMs work through three mechanisms: parameters (compressed knowledge), reasoning (derived knowledge), and web access (searched knowledge).
  • The parameter mechanism models all human knowledge as mathematical relationships between tokens, represented by billions of weights.
  • The reasoning mechanism allows models to infer knowledge not explicitly stored in parameters, reducing the need for exhaustive memorization.
💡 Why it matters: This clear breakdown helps developers and AI practitioners quickly grasp the fundamental workings of LLMs, which is useful for debugging, optimizing, and explaining model behavior in real-world applications.
🇨🇳 这个通俗易懂的拆解能帮开发者快速理解大模型的基本运作原理，对调试、优化和向他人解释模型行为都很有用。

科技爱好者周刊（第 408 期）：你需要知道的 AI 缓存知识

阮一峰周刊 🟢 Privacy

This week's digest explains the often-overlooked 'cached input token' pricing in LLM APIs, where cache hits can cost as little as 1/50th of normal input tokens. It details why caching exists, how long caches last across providers (Anthropic 5 min, DeepSeek/OpenAI 10-30 min, Google up to 1 hour), and how AI agents keep caches alive by sending periodic activation requests—now recommended every 4 minutes instead of 30 seconds.

本期周刊把大模型定价里最容易被忽略的「缓存命中价」讲透了：命中缓存时输入 Token 只要 2 分钱，是未命中的五十分之一。文章还对比了各家缓存的有效期（Anthropic 5 分钟、DeepSeek/OpenAI 10~30 分钟、Google 1 小时），并指出 AI Agent 为了省钱会定期「续命」缓存，最新建议是每 4 分钟激活一次，而不是 30 秒。

  • LLM input tokens are charged because computing attention over prompt tokens is compute-intensive.
  • Cache hits are cheap because cached prefix computations are reused, costing only storage rather than compute.
  • Cache lifetimes vary: Anthropic 5 min, DeepSeek 10 min, OpenAI 10-30 min, Google up to 1 hour.
💡 Why it matters: Developers building multi-turn agents or long-context applications can drastically cut API costs by structuring prompts to maximize cache hits and tuning cache keep-alive intervals.
🇨🇳 做多轮对话或长上下文应用的开发者，只要优化提示词结构、合理设置缓存续命间隔，就能大幅降低 API 费用。
