  • Apple evaluated eight Chinese AI vendors over three years (Baidu, Alibaba, ByteDance, Tencent, DeepSeek, Baichuan, Moonshot, Zhipu) before selecting Alibaba's Qwen.
  • Alibaba won because it is the least competitive threat to Apple—no smartphone, short-video, or search-ad business—and can meet compliance, privacy, and engineering delivery requirements.
  • Qwen handles roughly 65% of tasks as the core model, while Baidu's Ernie is embedded in Siri voice interaction and visual search (~35%), deliberately splitting the tech stack.

折腾了整整1年，毫无保留地分享一下我这套Agent自动化系统。

虎嗅 (AI原生100等) 🔴 Factual

The author shares a year-long journey building an Agent automation system inspired by DeepSeek's Super-agent design paper, which argues that human attention is the bottleneck in multi-task Agent systems. The core architecture uses an event-driven middle platform to trigger Agents via webhooks and scheduled tasks, routing events to different models based on task type, and only surfacing decisions to the human through Feishu cards for final approval.

作者花了一年时间搭建了一套Agent自动化系统，灵感来自DeepSeek的Super-agent设计文章——人的注意力才是多任务Agent系统的真正瓶颈。核心思路是搞一个事件驱动中台，用Webhook和定时任务自动唤醒不同模型处理不同任务，人只在飞书里点卡片做最终决策，像皇帝批奏折一样。

  • DeepSeek's Super-agent paper highlights that humans can only track 3-5 active sessions, making human attention the key bottleneck
  • The system uses an event-driven middle platform to unify all triggers (webhooks, scheduled tasks) and route them to appropriate Agents and models
  • Different events wake different models (Claude Opus, GPT variants) based on task type to optimize cost and token usage
💡 Why it matters: This provides a practical blueprint for developers building multi-Agent orchestration systems, showing how event-driven architecture and model routing can free humans from being the bottleneck in Agent workflows.
🇨🇳 为开发者构建多Agent编排系统提供了实用蓝图，展示了事件驱动架构和模型路由如何让人从Agent工作流的瓶颈中解放出来。
