当 AI 开始给自己动刀，“智能爆炸”可能真不远了：两篇论文拆解AI下一步进化路径

钛媒体 🔴 Factual 🟡 Bias

Two recent arXiv preprints—MIT's SwarmWorld and ModularRSI from Beihang, Manchester, and Langboat—explore recursive self-improvement beyond model parameters. SwarmWorld shows that 50–200 identical LLM agents in a shared physical simulator can spontaneously develop roles, accumulate technology, and exhibit stigmergy-based collaboration without explicit chat. ModularRSI decouples an agent's execution harness into five modules, using contrastive trajectory analysis and validation gates to evolve the harness without overfitting to benchmarks.

最近两篇 arXiv 预印本火了：MIT 的 SwarmWorld 让 50–200 个相同 LLM 智能体在共享模拟世界里自发分工、积累技术，甚至不靠聊天，靠环境痕迹就能协作；北航、曼大等团队的 ModularRSI 则把智能体的执行外壳拆成五个模块，通过对比轨迹和验证门控来进化，避免“背考题”。两者都指向同一个趋势：AI 的自我改进，正从模型参数转向模型之外的共享环境和执行机制。

  • SwarmWorld: 50–200 identical LLM agents in a shared physical simulator spontaneously develop roles and accumulate technology over 3000+ timesteps.
  • Stigmergy (indirect collaboration via environment) outperforms explicit chat for reuse; shared world builds a thicker 'civilization base' rather than smarter individuals.
  • ModularRSI decouples the agent harness into five modules and uses contrastive trajectory analysis plus validation gates to evolve it without overfitting.
💡 Why it matters: Developers building AI agents should consider providing shared environments where agents leave reusable artifacts, rather than forcing endless meetings; and modular harness evolution with validation gates can improve agent reliability without benchmark overfitting.
🇨🇳 做 AI 智能体的团队，与其让智能体没完没了地开会，不如给它们一个能共同留下痕迹、共享成果的环境；同时，用模块化外壳演化和验证门控来提升智能体可靠性，避免在基准上过拟合。
