# 🤖 Daily AI Digest

Daily bilingual (English + Chinese) AI/IT industry news digest — automatically generated by [DeepSeek](https://deepseek.com), deployed to GitHub Pages.

## Features

- **🔍 Multi-source aggregation**: RSS feeds (20+ sources), Reddit, GitHub Trending, web search
- **🧠 AI-powered curation**: DeepSeek scores and filters articles by relevance (>0.7 threshold)
- **🌐 Bilingual**: English summaries + natural Chinese translations
- **🛡️ Quality control**: 4-layer AI critic validation (factual, safety, bias, privacy)
- **🎨 Modern UI**: Dark/light theme, search, topic filtering, responsive design
- **⚡ Zero server**: Runs entirely on GitHub Actions + GitHub Pages (free)
- **📅 Daily**: Auto-generated every day at 08:00 Beijing time

## Pipeline

```
Sources → Content Gate → Dedup → Quality Score → Relevance Filter
       → AI Summarize (DeepSeek) → 4 Critics → Topic Classify → Render → Deploy
```

## Setup

### 1. Fork this repository

### 2. Enable GitHub Pages

Go to Settings → Pages → Source: **GitHub Actions**

### 3. Set secrets

Go to Settings → Secrets and variables → Actions → add these secrets:

| Secret | Required | Description |
|--------|----------|-------------|
| `DEEPSEEK_API_KEY` | ✅ Yes | DeepSeek API key from [platform.deepseek.com](https://platform.deepseek.com) |
| `TAVILY_API_KEY` | ⬜ Optional | For web search, free tier at [tavily.com](https://tavily.com) |
| `REDDIT_CLIENT_ID` | ⬜ Optional | Reddit API client ID |
| `REDDIT_CLIENT_SECRET` | ⬜ Optional | Reddit API client secret |

### 4. Customize sources

Edit `config/sources_en.yaml` and `config/sources_cn.yaml` to add/remove RSS feeds.

### 5. Run

The workflow triggers automatically at 08:00 Beijing time daily. Or go to Actions → Daily AI Digest → **Run workflow** to test.

## Configuration

All thresholds and settings are in `config/settings.yaml`:

```yaml
pipeline:
  min_content_length: 600       # Drop short articles
  min_relevance_score: 0.7      # DeepSeek relevance threshold
  max_articles: 30              # Max articles in digest
```

## Tech Stack

- **Python 3.12** — pipeline orchestration
- **DeepSeek API** — AI summarization, translation, critics (OpenAI SDK compatible)
- **feedparser** — RSS ingestion
- **PRAW** — Reddit API
- **Jinja2** — HTML templating
- **GitHub Actions** — scheduling + execution
- **GitHub Pages** — static site hosting

## Cost

Running daily (30 articles/day) with DeepSeek API: approximately **$15-30/month**.
